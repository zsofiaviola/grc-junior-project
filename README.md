# Junior GRC Project

This repository contains a junior-level practice project focused on
Governance, Risk, and Compliance (GRC) fundamentals in cybersecurity.

## Project scope
- Risk identification and assessment
- Incident management overview
- Business Continuity (BCP) and Disaster Recovery (DRP)
- Regulatory awareness (KiberTV, NIS2, ISO/IEC 27001, CIS Controls)
